#Zomato Data Science & Machine Learning Project
📌 Project Overview

This project focuses on analyzing Zomato restaurant data to extract meaningful insights and build a predictive machine learning model. The workflow includes data cleaning, visualization, model building, and dashboard creation to support data-driven decision-making.

🎯 Objectives
Clean and preprocess raw Zomato dataset
Perform exploratory data analysis (EDA)
Visualize trends and patterns using graphs
Build a machine learning model using Random Forest
Create an interactive dashboard using Power BI
🛠️ Technologies Used
Python (Pandas, NumPy)
Data Visualization: Seaborn, Matplotlib
Machine Learning: Scikit-learn (Random Forest)
Data Pipeline: Data preprocessing and transformation
Dashboarding Tool: Power BI
📊 Data Cleaning & Preprocessing
Removed duplicate records
Handled missing values
Converted categorical data into numerical format
Standardized column names and formats
Feature selection for model building
📈 Data Visualization

Used Seaborn and Matplotlib to explore insights such as:

Restaurant ratings distribution
Cost vs rating analysis
Popular cuisines and locations
Online order and table booking impact
🤖 Machine Learning Model
Applied Random Forest Classifier/Regressor
Split dataset into training and testing sets
Performed feature engineering
Evaluated model using metrics like accuracy and F1-score
Improved model performance through tuning
🔄 Data Pipeline
Created a structured pipeline for:
Data cleaning
Feature transformation
Model training
Ensures reproducibility and scalability
📊 Power BI Dashboard
Built an interactive dashboard for visualization
Key insights included:
Top-rated restaurants
Cost distribution
Location-based analysis
Enables easy understanding for non-technical users
